A More Organized Process

From Documents to a Clear Result

A simple overview of the typical document workflow, from selecting files to reviewing the portal result.

Select Your Documents

Set your customer root folder in Settings → Preferences. Choose documents finds the folder matching the customer name on VAHAN. Pick individual files or select all; manual browsing stays available.

Prepare and Match

Supported files are prepared, compressed where applicable and matched to document categories. Keep the extension open during preparation and assign any unmatched files before starting.

Run the Upload Workflow

Start uploads, with the option to skip documents identified as already uploaded. Once the monitor appears, close the popup and work in other tabs or apps. Keep the VAHAN tab open until completion.

Review the Result

Review your application summary, optionally copy the details, and confirm the final status on the official VAHAN portal.

FOUR BUTTONS · FOUR WAYS TO START

The four document buttons.
What each one does.

Choose documents for review. Auto-import available for quick matching. Import unuploaded docs to reuse saved categories or scan VAHAN. Browse files manually for any folder. Here is exactly how each button works.

01 / REVIEW FIRST

Choose documents

Finds the folder matching the customer name on VAHAN under your saved root. Opens the available files so you can preview them, tick individual documents or Select all, then add your selection.

Best for careful selectionChoose the correct version when a category has multiple files, or select only the documents you need.
No root folder saved? This button opens the normal file picker.
02 / FEWER CLICKS

Auto-import available

Reads the matched customer folder and imports one unique filename match per document category. Preparation starts immediately. It works with fewer than 12 categories; there is no need to wait for a complete set.

Best for ready customer foldersSkip repeated file selection. Categories with multiple matches are skipped so you can review them with Choose documents.
Requires a saved root folder and read access. Unrecognized files are left for manual selection.
03 / VAHAN-AWARE IMPORT

Import unuploaded docs

Reuses remaining categories from a valid cache matching the customer name and chassis. Without a usable cache, scans VAHAN from the first slot until the first uploaded document, then saves the remaining categories. Shift-click the button to force a fresh scan.

Best for avoiding repeat preparationImports only unique customer-folder matches for categories VAHAN still needs, then starts normal local preparation.
A lightweight scanning barrier prevents other document actions until VAHAN returns to the first document.
04 / CHOOSE ANY LOCATION

Browse files manually

Opens the normal file picker directly. Select documents from any location, without using the saved root folder or matching a customer name.

Best for exceptions and extra filesAdd a document from Downloads, another folder, or a location outside the usual customer folder.
Your selection enters the same document preparation workflow.

All four routes prepare selected files locally. Uploading starts automatically only when Automatic Upload is enabled; otherwise use Start. Your original files stay unchanged.

NEW PREFERENCE · OFF BY DEFAULT

Auto import/prepare/upload documents in CX folder

Enable this red-highlighted option in Settings → Preferences. After sign-in, opening the document workspace checks for a valid matching customer cache once. No cache selects Auto-import available; a matching cache selects Import unuploaded docs. Unique matching files are then prepared.

Why enable it? Remove the repeated import click when working through customers whose folders are already organized. Partial sets can start preparation immediately.

Choose how far automation goes

  1. Import on openingThe CX folder preference chooses available or unuploaded-only import based on the matching cache. Save your root folder first; folder permission may still need your click.
  2. Prepare selected filesPreparation follows import. Enable Convert images to PDF separately if you want that format.
  3. Upload when readyEnable Automatic Upload to continue without pressing Start. Leave it off to review prepared files first.

Automatic File Movement & Submission remains a separate preference. The new option does not switch it on or change your upload settings.

Tools that help reduce repetitive document preparation and upload tasks while keeping users in control of the official VAHAN process.

Automatic Customer Folder Matching

Choose your customer root folder once. The extension matches the VAHAN customer name to a folder, ignoring case and punctuation. Browse manually whenever you need another location.

Auto-import Available Documents

Import available unique document matches from the customer folder in one click, even with fewer than 12 categories. Duplicate matches are skipped for review. Choose documents opens the preview and manual selection workflow.

Automatic Aadhaar Front + Back Merge

Name the front file 1 and the back file 2, keeping their file extensions. Select both together: the extension combines them in that order into Aadhaar.pdf and assigns Address Proof → Aadhaar automatically. Works with PDF, JPG, PNG and WEBP files from manual selection or your customer folder.

Optional Auto Image to PDF Conversion

Enable AUTO img to PDF CONVERTION in the extension settings. Prepare supported images as PDFs with a saved preference that fits your team. Review clear preparation results before continuing with your documents.

Conversion Results at a Glance

See a success notice after images are compressed and converted. Converted files display PDF tiles and PDF filenames in the file list. Enabled settings appear as green highlights below the notice.

Prepare documents within 400 KB (400,000 bytes), with the existing smaller Form 20 limit. Files that cannot meet their limit are skipped.

Auto-Start After Preparation

Flexible Automation Settings

Choose the automation options that suit your workflow instead of being locked into one fixed process.

Smart Customer Document Cache

Keep up to 50 customers on this device, identified by chassis number and checked against the customer name. Saved remaining categories help resume partial document work.

Flexible Automatic Import

With no valid customer cache, automatic import selects available documents. With a matching cache, it selects Import unuploaded docs. Preparation follows; Automatic Upload remains a separate setting.

Automatic Customer & Chassis Filenames

Prepared copies always use customername_assigneddocument_chassisnumber.extension, such as suresh_form20_MBLHAW427THH02338.pdf. Renaming is automatic with no user toggle. Original files remain unchanged.

Save Prepared Copies to the Customer Folder

Enable Always store prepared docs in customer folder and grant write access. Ready copies are saved under Customer Root / Customer Name / Compressed. Same-name prepared files are replaced; original documents stay unchanged.

Reuse Prepared Documents

Choose documents, Auto-import available, and Import unuploaded docs check Compressed for matching customer and chassis files. Reuse usable copies and prepare originals for missing categories. Choose documents continues to show original filenames.

Prepare Originals Again When Needed

The session-only Use original files and prepare again checkbox ignores Compressed, selects main-folder originals, and writes replacement prepared copies after processing. It resets with a new workspace and is never saved as a permanent preference.

Cache Updates After Upload

Confirmed uploads remove their categories from the remaining list. Completing all documents clears the customer record. Stale records expire, and the oldest entries are removed when the cache exceeds 50 customers.

Submission Logs

Choose the customer and application details shown in submission logs. Review completed work and copy the details you need.

Document Previews

Review supported images and PDFs before uploading, check document assignments, and select files manually when a filename cannot be recognized.

Feature availability depends on the supported VAHAN page and the options enabled in your extension and account.

Frequently Asked Questions

Learn more about NDC VAHAN TOOL, its workflow, supported formats and subscription plans.

Where are prepared documents saved?

Under Customer Root / Customer Name / Compressed, for example Suresh / Compressed / suresh_aadhar_MBLHAW427THH02338.pdf. Enable Always store prepared docs in customer folder and approve write access with Allow saving to customer root. Original documents are not overwritten.

Will it reuse files that were already prepared?

Yes. Choose documents, Auto-import available, and Import unuploaded docs check Compressed for matching prepared copies. Missing categories use originals. Choose documents keeps original filenames visible. The extension checks the customer name, chassis, category, size, and whether an original is newer.

How do I force fresh preparation?

Check Use original files and prepare again in the document workspace before importing. It ignores Compressed files for this session, prepares the main-folder originals, and writes same-name replacement copies with write access. This option is not stored as a permanent setting.

Can automatic renaming be switched off?

No. Renaming is automatic and has no visible setting. Prepared filenames contain the customer name, assigned category, and chassis number. Original disk filenames stay unchanged.

Why are there four document selection buttons?

Choose documents opens the matched customer folder for preview and selection. Auto-import available selects unique category matches and starts preparation, even with fewer than 12 categories. Import unuploaded docs uses a valid saved customer category list, or scans VAHAN when no usable cache exists, and imports only categories that still need files. Browse files manually opens the normal file picker for any location.

Does the new CX folder preference upload immediately?

It checks for a matching customer cache once when the signed-in document workspace opens. Without a valid record, it triggers Auto-import available. With a matching record, it triggers Import unuploaded docs using the saved remaining categories. Upload starts after preparation only if Automatic Upload is enabled. Automatic File Movement & Submission is controlled separately. The CX folder preference is off by default.

What if a customer folder has missing or duplicate documents?

Available unique matches are imported without waiting for all 12 categories. Categories with multiple matches and unrecognized filenames are left for manual review. Use Choose documents to preview and select those files, or Browse files manually to add documents from another location.

How do I set up automatic customer folders?

Open Settings → Preferences → Choose root folder and grant read-only access to the folder containing your customer folders. Name each customer folder like the customer name on VAHAN. Click Choose documents to open the matching folder’s document list. Case and punctuation are ignored; only folders directly inside the root are matched.

What if a customer folder cannot be matched?

The extension shows a message when the name is missing, no folder matches, or multiple folders match. Use Browse manually below Choose documents to select the correct files. Chrome may ask you to restore folder access, and setup can open in a separate workspace tab.

Can I merge separate Aadhaar front and back files automatically?

Yes. Use exact filenames such as 1.jpg for the front and 2.jpg for the back, then select both documents. One unambiguous pair is combined front first, back second into Aadhaar.pdf, with Address Proof → Aadhaar selected automatically. Mixed supported formats work too, such as 1.png and 2.pdf. No extra setting is needed, and image-to-PDF conversion can remain off. Preview the merged PDF before uploading; normal document size limits still apply. Names such as front1.jpg or back2.jpg do not trigger merging.

Can I convert images to PDF?

Yes. Enable Auto Image to PDF Conversion to prepare supported images as PDFs. It is off by default, and your preference is saved. With it off, images keep their image format. Review the preparation results and applicable document size limits before uploading.

What is NDC VAHAN TOOL?

NDC VAHAN TOOL is a Chrome extension designed to simplify supported document preparation and upload workflows on VAHAN portal pages.

Which document formats are supported?

The extension supports JPG, PNG, WEBP and PDF files. Actual upload requirements depend on the selected document category and the VAHAN portal's applicable requirements.

Can I do other work while documents upload?

Yes. Keep the extension open during preparation and resolve any unallocated files. Once uploads start and the document monitor appears, close the popup and work in other tabs or apps. Keep the VAHAN tab open and avoid changing its active application until the workflow finishes. Check the monitor and final portal result when complete.

Can uploads start automatically?

Yes. Enable Auto-Start Upload to initiate the upload workflow after document preparation and compression are complete.

Can it skip documents already uploaded?

Yes. When Skip Already Uploaded Documents is enabled, the tool checks the VAHAN document workflow and skips documents it identifies as already uploaded.

Can the tool complete final submission?

The optional automatic final submission setting can continue the supported submission workflow after document uploads are processed. Users should verify the final submission status on the official VAHAN portal.

Does the tool provide an upload summary?

Yes. Follow live upload activity and document counts, then view a readable application summary with customer, chassis, date, owner, insurance and finance details. Automatic submission includes the destination RTA office. Summary details are saved locally in your browser.

Can I copy the application details automatically?

Yes. Enable Auto Copy Logs to Clipboard in the extension settings, or use Copy details in the summary. You get only the application details, with completion status, date and time, without activity messages or branding. Automatic copying is optional and off by default.

Can I hide the logs or summary?

Yes. Activity logs can be collapsed while updates continue. You can also choose whether the application summary appears on the page, independently of the automatic clipboard setting.

Can I download my prepared documents?

Yes. Use Download ZIP to download the prepared documents together in a ZIP archive.

Does the extension require an account?

Yes. Users access the extension through an authorized account. Account approval, access permissions and configured session limits are managed through the authentication system.

Does the tool replace the official VAHAN portal?

No. NDC VAHAN TOOL assists with supported document-processing and upload steps. Users remain responsible for checking document accuracy and completing official portal requirements.

Will compression affect document clarity?

Compression is designed to reduce file sizes while keeping documents usable. Always review prepared files to ensure important text and details remain readable before submission.
